# SwissData

SwissData — набор программ для приёма, обработки и просмотра данных спортивного тайминга.

Проект собирался под практическую работу на тренировках и соревнованиях: данные приходят от системы хронометража, сохраняются, а затем используются для статистики, протоколов и анализа результатов спортсменов.

## Что входит в комплект

- `QuantumServerQt.exe` — основной сервер приёма и обработки данных;
- `SwissStatsService.exe` — web-сервис со статистикой;
- `QuantumClient.exe` — клиент для работы с данными и подготовки протоколов;
- `QuantumSimulator.exe` — генератор тестовых данных.

Названия и состав файлов могут немного меняться между версиями.

## Возможности

- приём данных от тайминга;
- список категорий и спортсменов;
- история заездов по каждому спортсмену;
- хранение промежуточных отсечек;
- определение лучших результатов;
- рейтинг внутри категории;
- подготовка протоколов;
- web-страница для просмотра статистики;
- симуляция входящих данных без реального оборудования.

## Быстрый запуск

Обычный порядок работы:

1. Запустите `SwissStatsService.exe`.
2. Запустите `QuantumServerQt.exe`.
3. Откройте страницу статистики в браузере.
4. При необходимости запустите `QuantumClient.exe` для работы с протоколами.

Адрес web-интерфейса и используемые порты зависят от конфигурации текущей сборки.

## Работа со статистикой

В web-интерфейсе можно:

- выбрать категорию;
- выбрать спортсмена;
- посмотреть его заезды;
- сравнить результаты;
- открыть список отсечек;
- посмотреть лучший результат;
- увидеть рейтинг спортсменов категории.

## Тестирование без оборудования

Для проверки интерфейса и логики используется:

```text
QuantumSimulator.exe
```

Симулятор удобен перед соревнованием: он позволяет проверить соединение между компонентами, отображение результатов и сохранение данных без подключения реального тайминга.

## Подготовка к работе на соревновании

Перед использованием на старте стоит заранее проверить:

- доступность нужных портов в локальной сети;
- соединение между сервером и компьютерами операторов;
- корректность категорий и стартовых списков;
- сохранение результатов после перезапуска;
- отображение статистики с другого устройства;
- системное время на всех компьютерах.

Рабочую базу и конфигурацию лучше копировать перед каждым мероприятием.

## Для кого проект

SwissData рассчитан прежде всего на тренеров, судей и операторов систем хронометража. Это специализированный инструмент, а не универсальная платформа для любых видов спорта.

## Состояние проекта

Проект развивался под конкретные рабочие сценарии, поэтому некоторые настройки пока требуют ручной подготовки. Перед использованием в новом окружении рекомендуется сначала запустить систему с симулятором и тестовыми данными.

В дальнейшем имеет смысл добавить единый установщик, описание сетевого протокола, автоматическое резервное копирование и более подробную диагностику соединений.
